# edx site

    npm install
    npm run dev

Fill in `src/data/site.js` (WhatsApp, email, phone, LinkedIn, Twitter) and `src/data/testimonials.js`.
Add design work: put the image in `public/works/design/<folder>/` and add a line in `src/data/works.js`.
Netlify: build `npm run build`, publish `dist` (set in `netlify.toml`).
